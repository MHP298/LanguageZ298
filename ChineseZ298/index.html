Cài đặt Gemini API Key cá nhân

Sử dụng API Key cá nhân giúp dịch thuật không giới hạn và phát âm giọng AI chuẩn bản ngữ:

📌 Hướng dẫn từng bước tại Google AI Studio:

1. Bấm nút "Mở Google AI Studio" và đăng nhập bằng tài khoản Gmail của bạn.

2. Bấm vào nút màu xanh "Create API key".

3. Nếu bạn chưa có dự án: Chọn "Create project" hoặc để mặc định "Default Gemini Project" rồi bấm "Create key".

4. Bấm "Copy" chuỗi mã bắt đầu bằng AIzaSy... và dán vào ô bên dưới.

API HIỆN TẠI CỦA BẠN:
Mở Google AI Studio
